# nb-base-releases

Dépôt de distribution du thème WordPress **NB Base**.

Il contient uniquement les versions publiées du thème (`releases/`) et le fichier `info.json`, que les sites équipés du thème consultent pour proposer les mises à jour dans leur tableau de bord. Aucun code source ni aucune donnée de site ne s'y trouve.
